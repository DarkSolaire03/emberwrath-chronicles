# Emberwrath Chronicles

> "Where ash remembers fire, and every throne is paid for in blood."

A dark fantasy lore and story site for **Obsidara** — a shattered obsidian realm of ruined kingdoms, ember storms, and a throne carved from living black glass. Published with [GitHub Pages](https://darksolaire03.github.io/emberwrath-chronicles/).

## Live site

🌐 **https://darksolaire03.github.io/emberwrath-chronicles/**

## What's on the site

- **Hero** — the title, tagline, and links into the Characters and Chronicles.
- **The World** — lore for Obsidara: the shattered realm, ember storms, ruined kingdoms, and the Obsidian Throne.
- **Characters** — lore cards for the five souls who shape the fire (click a card to read more):
  - **Inferna** — The Ember Saint / Flame Oracle
  - **Malphur** — The Ashen Warlord / Oath-Breaker Knight
  - **Baelfire** — The Hellfire Prince / Cursed Fire Entity
  - **Emberwrath** — The Living Cataclysm / ancient wrath embodied
  - **Obsidara** — The Obsidian Queen / heart of the realm
- **Chronicles** — a chapter index with opening excerpts:
  - Chapter I — *Ashes of the First Throne*
  - Chapter II — *The Oath That Broke the Sky*
  - Chapter III — *The Queen of Black Glass*
- **Realm Timeline** — from the Founding of Obsidara through the Shattering, the Ember War, and the waking Emberstorm.

## About this project

The site is a single self-contained `index.html` (inline CSS and JavaScript, no build step) with a dark gothic design — black and charcoal, ember orange-red and antique gold, elegant serif headings, a sticky nav, smooth scrolling, expandable character cards, and a drifting ember atmosphere.

The lore is placeholder starting material, written to be edited and expanded. All character lore, chapters, and timeline events can be changed freely in `index.html`.

## Editing

- Edit `index.html` directly on GitHub (or clone the repo) — no build step is needed.
- The site is deployed from the `main` branch, root folder, via GitHub Pages.
