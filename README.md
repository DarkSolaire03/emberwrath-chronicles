# Emberwrath Chronicles

## 🌐 Live Site: [darksolaire03.github.io/emberwrath-chronicles](https://darksolaire03.github.io/emberwrath-chronicles/)

> "Where ash remembers fire, and every throne is paid for in blood."

## About

**Emberwrath Chronicles** is a dark fantasy lore and story site for **Obsidara** — a shattered obsidian realm of ruined kingdoms, ember storms, and a throne carved from living black glass.

Step into a world where fire remembers, oaths break the sky, and every ruler pays for their throne in blood. The site gathers the realm's world, its characters, its chronicles, and its timeline in one place, so readers can explore Obsidara piece by piece.

## How to Use It

1. Open the live site: **https://darksolaire03.github.io/emberwrath-chronicles/**
2. Start with the hero section, then use the sticky navigation to jump to **The World**, **Characters**, **Chronicles**, or the **Realm Timeline**.
3. Click a character card to expand it and read more about that character.
4. Read the chronicles in order, from Chapter I to Chapter III, and follow the timeline to see how the realm's history fits together.

## The World of Obsidara

Obsidara is a shattered obsidian realm — a land of ruined kingdoms, drifting ember storms, and the Obsidian Throne at its heart. Its history is written in ash: kingdoms rise on fire and fall on broken oaths, and the Emberstorm that once shaped the realm is waking again.

## How to Edit / Update It

You do not need any special tools to update this site:

1. Open `index.html` in this repository on GitHub.
2. Click the pencil (**Edit**) icon, make your changes, and commit them.
3. GitHub Pages redeploys the site automatically — your changes appear on the live site within a few minutes.

The lore is a work in progress — starting lore that can be edited and expanded. All character lore, chapters, and timeline events can be changed freely in `index.html`.

## Tech Notes

- **Single `index.html`** with inline CSS and JavaScript — no build step, no framework, and no separate files to manage
- Hosted on **GitHub Pages**, deployed from the `main` branch, root folder
- Includes a `.nojekyll` file so GitHub Pages serves the site exactly as written
